FusionWifi (ESP32) — 与 PC 融合服务通信（TCP 一行 JSON）

================================================================================
推荐：手机热点（校园网不稳定时优先用）
================================================================================

拓扑（最简单）：
  手机开热点（2.4GHz） → 笔记本电脑连该热点 → 两块 ESP32 也连同一热点
  → 笔记本运行 Python（server.py）→ 浏览器访问笔记本的网页

注意：
  - ESP32 只支持 2.4GHz Wi‑Fi。请在手机里打开「允许 2.4GHz」或关闭「仅 5GHz」类选项。
  - 笔记本、手机热点、ESP 必须在同一套 Wi‑Fi 里，FusionWifi_config.h 里的 FUSION_HOST
    必须填「笔记本在热点网段里的 IP」，不是手机 IP。

--------------------------------------------------------------------------------
A. 手机端（开热点）
--------------------------------------------------------------------------------

Android / iOS 均可。记下：
  - 热点名称（SSID）→ 填 STASSID
  - 热点密码      → 填 STAPSK

--------------------------------------------------------------------------------
A2. 怎么确认板子已经连上热点？
--------------------------------------------------------------------------------

1）串口监视器（最可靠）
  - Arduino IDE：工具 → 端口 → 选 ESP32；波特率 thermal / proximity 均用 115200（与代码一致）。
  - 若仍为空白：按一下开发板 RESET，或关掉串口监视器再打开；Mac 上 USB 串口有时需多等 1 秒。
  - 烧录含 FusionWifi 的固件后，上电几秒内应出现：
      [FusionWifi] ========== WiFi STA connected ==========
      [FusionWifi] ESP32 IP: x.x.x.x  (should be same subnet as <你的 Mac IP>)
      [FusionWifi] Gateway: ...
  - 若一直没有这几行：检查 STASSID/STAPSK、2.4GHz、手机是否允许连接数。
  - 触发一次进门/计数后，若成功连上 Python 的 TCP 8766，会再出现一行：
      [FusionWifi] First TCP send to fusion PC OK ...
    若出现 TCP connect FAILED：检查 Mac 的 IP 是否仍是 FUSION_HOST、防火墙是否放行 8766、server.py 是否在运行。

2）iPhone：设置 → 个人热点 → 已连接设备里是否能看到多一台（名称可能不显示为 ESP）。

3）网页仍为 0：连上热点只表示「能上网段」；人数更新要嘛 ESP 发 JSON（TCP），要嘛点网页 Simulate events。若串口已显示 WiFi connected 但从未 First TCP OK，多半是 Mac IP 或防火墙问题。

--------------------------------------------------------------------------------
B. 笔记本：连热点后查自己的 IP（用来填 FUSION_HOST）
--------------------------------------------------------------------------------

macOS：
  系统设置 → 网络 → 选当前 Wi‑Fi（你的热点名）→ 查看 IP 地址
  或终端执行：ipconfig getifaddr en0   （若不对可试 en1，或用「网络」里显示的接口）

Windows：
  设置 → 网络和 Internet → WLAN → 属性 → IPv4 地址
  或 cmd：ipconfig  → 找「无线局域网适配器 WLAN」下的 IPv4

常见网段（仅作参考，以你电脑为准）：
  - Android 热点：电脑常为 192.168.43.x 或 192.168.137.x
  - iPhone 热点：电脑常为 172.20.10.x

把查到的「笔记本 IPv4」原样写入 thermal/proximity 的 FusionWifi_config.h 里 FUSION_HOST。

--------------------------------------------------------------------------------
C. 检查 / 放行防火墙（否则 ESP 和浏览器访问不了 8765、8766）
--------------------------------------------------------------------------------

需要放行入站 TCP 端口：8765（网页与 WebSocket）、8766（ESP32 JSON 行）。

macOS：
  1）系统设置 → 网络 → 防火墙 → 若打开，可临时关闭做联调，或允许「python3」「Terminal」等入站。
  2）终端查看防火墙是否开启（可选）：
      /usr/libexec/ApplicationFirewall/socketfilterfw --getglobalstate

Windows：
  1）控制面板 → Windows Defender 防火墙 → 高级设置 → 入站规则 → 新建规则
  2）选「端口」→ TCP → 特定本地端口：8765,8766 → 允许连接 → 名称可写 Fusion ESP

联调技巧：防火墙搞不定时，可暂时关闭防火墙测一次；确认能通后再按需加规则。

--------------------------------------------------------------------------------
D. ESP32：怎么连热点
--------------------------------------------------------------------------------

1）用手机/电脑确认热点已开启，笔记本已连上并可上网（可选）。
2）在 Arduino 里改好 FusionWifi_config.h：
     STASSID / STAPSK = 热点名称与密码
     FUSION_HOST      = 上一节查到的笔记本 IP
3）烧录 thermal / proximity 对应固件。
4）串口监视器（波特率 thermal 115200，proximity 9600）可看 Wi‑Fi 是否连上；
   触发一次计数后，笔记本上应能看到 server.py 收到事件（或网页 Fusion log 有记录）。

若连不上热点：检查 2.4GHz、密码、SSID 是否含难输字符；离手机近一点。

--------------------------------------------------------------------------------
E. 怎么看网页（仪表盘）
--------------------------------------------------------------------------------

1）在笔记本上启动融合服务：
     cd project/web
     （激活 venv 后）python server.py
     或：uvicorn server:app --host 0.0.0.0 --port 8765

   必须监听 0.0.0.0，手机或其它设备才能用「笔记本IP」访问。

2）在同一热点下的手机或第二台电脑浏览器打开：
     http://<笔记本IP>:8765/
   例如：http://192.168.43.12:8765/

3）本机也可：http://127.0.0.1:8765/

--------------------------------------------------------------------------------
F. 文件与端口（默认）
--------------------------------------------------------------------------------

- thermal/ 与 proximity/ 目录内需有 FusionWifi.h / FusionWifi.cpp / FusionWifi_config.h
- FusionWifi_config.example.h 可复制为 FusionWifi_config.h 再修改
- PC：HTTP 8765，TCP 8766（与 server.py 中 FUSION_TCP_PORT 一致）
- 时间戳：由 PC 在收到 JSON 时写入 ts_ms，ESP 无需 NTP

================================================================================
（以下为英文简要，便于对外说明）
================================================================================

Copy FusionWifi.* next to each .ino sketch. Edit FusionWifi_config.h (SSID, password,
laptop IP on the same LAN as ESP32, port 8766). Run server.py on the laptop; open
http://<laptop-ip>:8765/ on any device on the same network.
