Wi-Fi integration

Primary path (lab-style Wi-Fi): each ESP32 opens a TCP connection to <host>:8766, sends one JSON object per line ending with \n (same newline framing as lab07). The fusion server assigns ts_ms at receive time on the PC — ESP32 clocks are not used for pairing. Optional: POST http://<host>:8765/api/event with the same JSON fields. Fields: sensor, event_id, direction, delta_est, features, confidence_raw. Live UI: ws://<host>:8765/ws. Phone hotspot: put the laptop’s IPv4 on that hotspot in FusionWifi_config.h as FUSION_HOST; open http://<same-ip>:8765/. Use 2.4 GHz Wi‑Fi.
